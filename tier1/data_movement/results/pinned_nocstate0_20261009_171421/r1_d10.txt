# Baseline is host malloc + MADV_HUGEPAGE, NOT IoMem: the CXL mapping

# size and understated the gap on random access.
# Buffer sizes are chosen to EXCEED last-level cache: this CPU
# (Xeon 6756E) has 96 MiB of L3 per socket, so an 8 or 64 MiB walk
# never leaves cache and measures L3, not memory -- an earlier version
# of this test did exactly that and found CXL indistinguishable from
# DRAM (within 4%), which was a cache artifact.  Translation cost is
# measured separately (device TLB: 8 entries x 1 GB, ~590 ns/miss), not
# here: a TLB-resident buffer would have to be small enough to sit
# inside L3, so the two effects cannot be separated by buffer size.
